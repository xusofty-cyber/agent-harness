## Friction and suggestions

Suggestions only. No gate rule was changed by this branch.

1. `check-clean` cannot point at an equivalent interpreter. There is no
   flag or env var to tell dimension 2 to use `/tmp/bench-venv/bin/python`,
   so the operator must run `repo_checks.py` separately and explain the
   gap in prose. Suggestion: a `PASS_GATE_PYTHON` env override, documented
   as sandbox-only, with the raw dimension-2 result still shown.
2. A verification command written before the artefact can dictate content,
   not just behaviour. This report's verification required the literal
   string `agy --print`, so the report had to mention it even though the
   agy live-run was never part of this dogfood. Suggestion: prefer
   behaviour assertions; when a literal string is required, say why in
   the item notes so the next session does not mistake a mention for a run.
3. On hook-less hosts the gate is discipline plus the CI re-run. Nothing
   local enforces WIP=1 or blocks a hand-edit of `gate/feature_list.json`;
   the new checklist documents the discipline but cannot enforce it.
   Suggestion (needs a coordinator decision, since it changes enforcement):
   an opt-in local pre-commit check that refuses commits touching
   `gate/feature_list.json` without a matching `events.jsonl` append.
4. `check-clean` cannot distinguish a known-baseline FAIL from a real
   regression, so its "do not hand off yet" must always be overridden by
   a human sentence (as above). Suggestion: a recorded, reviewed
   known-baseline list — flagged as risky, because a stale entry would
   mask a real failure; do not add one without review.
5. Minor: the 60-line SESSION_STATE cap forced compression of the
   last-verification lines in session 2. It works, but the cap is doing
   real editorial work on every handover, not just preventing bloat.

What went smoothly, for balance: `add` / `start` / `verify` / `status`
all behaved as documented; the events log made the 21:51 break genuinely
resumable (session 2 needed about a minute of reading to know exactly
what was done and what was left); dimension 3b re-verifying old passing
